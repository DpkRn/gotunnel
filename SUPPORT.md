## 🆘 Getting Help

### For Questions:
- 💬 [GitHub Discussions](https://github.com/dpkrn/gotunnel/discussions) - Ask questions and share ideas
- 📝 [Issues](https://github.com/dpkrn/gotunnel/issues) - Report bugs or request features

### For Bugs:
1. Check [existing issues](https://github.com/dpkrn/gotunnel/issues) first
2. Search [discussions](https://github.com/dpkrn/gotunnel/discussions) for similar problems
3. [Create a new issue](https://github.com/dpkrn/gotunnel/issues/new) with:
   - Detailed description
   - Steps to reproduce
   - Environment details (OS, Go version)
   - Error messages or logs

### For Security Issues:
- 🔒 See [SECURITY.md](SECURITY.md) for responsible disclosure

## 🤝 Community

- Be respectful and constructive
- Search before asking to avoid duplicates
- Provide clear and detailed information
- Help others when you can

## 💡 Quick Start

```bash
# Installation
go get github.com/dpkrn/gotunnel

# Basic usage
tunnel := gotunnel.New("your-server-url")
tunnel.Connect("localhost:8080")
```

For more details, see [README.md](README.md).
